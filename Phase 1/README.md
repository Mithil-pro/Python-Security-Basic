\# Network \& File Health Checker



A Python automation tool that checks the health of a list of websites at

both the network level (ping) and web-service level (HTTP status codes).

Results are logged to timestamped reports and organized into a dedicated

folder automatically.



\## Features

\- Network reachability check using subprocess + ping

\- Web service availability check using the requests module

\- Automatic timestamped report generation

\- Automatic report folder organization using os

\- Summary count of fully healthy sites



\## Modules Used

\- subprocess

\- os

\- requests

\- datetime
